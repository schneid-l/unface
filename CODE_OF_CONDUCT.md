# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

All contributors, maintainers, and participants in project spaces are expected to uphold its principles: respectful, harassment-free collaboration, constructive criticism, and responsibility for the effect of one's words and actions on others.

## Reporting

To report behavior inconsistent with this code, contact the project maintainer(s) privately. Reports are reviewed confidentially.

## Scope

This code applies in every project-controlled space — the git repository, issue tracker, pull requests, discussions, and any off-platform communication conducted on behalf of the project.
